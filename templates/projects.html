Sentiment Analysis

During my internship, I worked on a Sentiment Analysis project that focused on identifying the sentiment expressed in text. The goal was to process text data and classify it based on whether the sentiment was positive, negative, or neutral.

My work involved preparing and preprocessing the text data, working with the machine learning model, and testing its predictions. I explored how text needs to be cleaned and transformed before it can be used by a machine learning model.

One of the things I learned from this project was how natural language processing and machine learning can be combined to make sense of human language. It also gave me practical experience working with real-world data and understanding the steps involved in building an ML application.
